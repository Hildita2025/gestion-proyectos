# Primer Proyecto React - Sistema de Gestión de Proyectos

## Descripción
Esta aplicación permite gestionar proyectos y tareas de manera simple utilizando **React** y **Next.js**.  
Cuenta con registro e inicio de sesión, gestión de proyectos y tareas, y un dashboard para ver el progreso.

## Cómo ejecutar la aplicación localmente

1. Clona el repositorio:
```bash
git clone https://github.com/tuUsuario/primer-proyecto-react.git
Instala dependencias:
npm install
Ejecuta la aplicación en modo desarrollo:
npm run dev
Abre tu navegador en:
http://localhost:3000
